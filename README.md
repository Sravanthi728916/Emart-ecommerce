 eMart — E-Commerce Application

## Project Description

eMart is a full-stack e-commerce web application developed to provide a user-friendly interface for browsing products across different categories and viewing product details.

##  Technologies Used

* **Frontend:** React.js
* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Version Control:** Git and GitHub

##  Features

* Browse products across different categories.
* View individual product details.
* Navigate between product pages.
* Interactive user interface built with React.
* Backend integration using Spring Boot.
* Database management using MySQL.

##  Setup and Installation

### Prerequisites

* Java JDK
* MySQL Server
* Maven
*  npm for running the React development environment

### 1. Clone the Repository

```bash
git clone https://github.com/Sravanthi728916/Emart-ecommerce.git
```

### 2. Configure MySQL

* Start your MySQL server.
* Create the required database.
* Configure the database connection in the Spring Boot application.

### 3. Run the Backend

Navigate to the backend directory and run:

```bash
mvn spring-boot:run
```

### 4. Run the Frontend

Navigate to the frontend directory and run:

```bash
npm install
npm run dev
```

Use the local URL displayed in the terminal to access the application.
